# InterviewMate

InterviewMate is a SwiftUI iOS app for tracking job applications, interview stages, notes, and follow-ups.

## Features

- Add, edit, and delete job applications
- Track company, role, status, application date, interview date, notes, and follow-up actions
- Search applications by company or role
- Filter applications by status
- View application status summary cards
- Save data locally using Codable and UserDefaults
- Fetch a daily motivational quote using URLSession and async/await
- Reusable SwiftUI components for cards, rows, and status badges

## Tech Stack

- Swift
- SwiftUI
- MVVM-style state management
- Codable
- UserDefaults
- URLSession
- async/await
- Xcode
- iOS Simulator

## Summary

Built a SwiftUI iOS job application tracker with local persistence, search/filter functionality, reusable UI components, and an async URLSession-based daily interview quote feature.
